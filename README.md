## Features

- **No-code GUI**: Point-and-click interface for the entire SRMA pipeline
- **Project-based**: All data saved in a single `poolr.json` file per project
- **PICO definition**: Define Population, Intervention, Comparator, Outcomes
- **Search strategy builder**: Generate PubMed/Embase/Cochrane/Scopus search strings
- **Screening tools**: Title/abstract and full-text screening with CSV import/export
- **Data extraction**: Import extraction CSV and manage study data
- **Risk of Bias**: RoB 2, NOS, PROBAST assessments
- **Meta-analysis**: Random-effects and fixed-effect models with forest/funnel plots
- **PRISMA output**: Generate PRISMA checklist and flow diagram

## Usage

1. **Open poolr.exe**
2. **Click "Open Project"** and select a folder
3. **Fill PICO** in the Protocol tab
4. **Build search strategies** in the Search tab
5. **Screen studies** in the Screening tab
6. **Extract data** in the Extraction tab
7. **Assess RoB** in the Risk of Bias tab
8. **Run meta-analysis** in the Meta-Analysis tab
9. **Export PRISMA** in the PRISMA tab

All data auto-saves to `poolr.json` in your project folder.
