# poolr — Visual Design Spec (v2 Addendum)

> Planning only. No code/fonts downloaded yet. This documents the locked visual language for the Tauri + React + Rust + C# overhaul.

## Typeface
- **Family:** Helvetica (Neue). Bundled in the Tauri binary (no internet at runtime).
- **Weights:** Helvetica (Regular/Bold) for UI chrome, headings, buttons; **Helvetica Light** for body/paragraph text and dense tables (easier on the eyes for long screening sessions).
- **Mono (stats/code):** Roboto Mono (neutral, pairs with Helvetica; not quirky).
- **Sourcing (open-source, non-commercial — no license required):** fetch free Helvetica-metric-compatible files at build time (e.g. **Arimo / Liberation Sans** as the Helvetica stand-in, plus a Light weight), embed via `@font-face` in `tauri.conf.json` bundle resources. Result: identical rendering on Windows/macOS/Linux.
- **Fallback chain:** `"Helvetica", "Helvetica Neue", "Arimo", "Liberation Sans", Arial, system-ui, sans-serif` ; mono: `"Roboto Mono", "Helvetica Mono", Consolas, monospace`.

## Radius (sharp-ish, not pill)
- Buttons / inputs: **6–8px** (precise, not toy-like).
- Cards / panels / modals: **10–12px**.
- No fully-rounded (pill) controls anywhere.

## Color (very dark grey + red, NOT slate)
- Base surface (app bg): **#0E0E10** (near-black grey, neutral — not blue/slate).
- Raised panel: **#141417**.
- Hairline border: `rgba(255,255,255,0.08)`.
- Text primary: **#EDEDED**; text muted: **#9A9A9E**.
- **Accent RED (brand/action):** `#E5484D` (hover `#F2555A`); deep variant `#C8121B` for active/selected.
  - Red is an *accent only* — primary buttons, active nav item, focus ring, key CTAs. Never a full-panel fill (harsh for hours of use).
- Success/Include (screening): green `#3FB950`; Exclude: `#F05252`; Unsure: amber `#F2B84B` — kept for screening decision semantics.

## Glass / Translucency
- **Chrome only** (sidebar, header bar, bottom status bar, modals): translucent layer over the dark base —
  `background: rgba(20,20,23,0.72); backdrop-filter: blur(20px) saturate(120%);` + 1px hairline border.
- **Content cards** (screening table, forms, KPI tiles): mostly **solid** dark panel + hairline border. Pure glass on dense content hurts legibility — avoid.
- Glass gives the premium frosted look; hairline borders keep edges *sharp* against the blur (matches the "not too rounded" requirement).

## Spacing (fixes "no margins")
- Global scale: 4 / 8 / 12 / 16 / 24px. Base content padding `p-4` (16px) minimum on every page; gaps `gap-3` (12px).
- Sidebar width 240px; header height 56px; status bar 28px.

## Net look
Very-dark-grey frosted shell · sharp-ish 6–8px corners · red as the single accent · Helvetica / Helvetica Light type. Precise, clinical, premium — distinct from the old slate CustomTkinter UI.

## Validation (manual, post-build)
- Open packaged build on a clean VM (no fonts installed) → Helvetica renders identically (bundled).
- 1280×720 and 1920×1080 → no overlap, consistent margins, red accent only on actions.
- 30-min screening session → eye-comfort check (Light weight, muted text).
